针对 2026-08-17 那一版的验收结果。**先说结论：合同的硬骨头你守住了**——洞察区留空、
CONFIDENCE 卡 0.40、LONG_GATE 关闭、数据台账逐项写明"本期不回答什么问题"、
零编造的资金流叙事。「空数组表示日历未知，不表示没有事件」这句是我没要求而你想到的，很好，保留。

下面按优先级列出必须修的。

---

## P0 · 整份报告只能有一个基准日

### 现在的 bug

同一个指标在报告里出现两个不同的值，而且在 HTML 里**并排显示**：

| 指标 | 观察区 | 旁边的卡片 / 表 |
|---|---|---|
| 科创50 / 上证 20日超额 | −4.02% | −0.8% |
| 上证红利 / 科创50 20日超额 | **+4.67%** | **−2.6%** ← 符号相反 |
| 上证指数 20日收益 | +4.33% | +4.9% |

根因：观察区按共同基准日 `2026-08-14` 计算，而表和卡片仍用各市场自己的最新日
（A 股 8/17）。8/17 科创 50 涨约 3%，正好解释全部差值——**两组数各自都对，
但放在同一份报告里就是自相矛盾**，读者无法判断该信哪个。

（这一半是原 prompt 的疏漏：只写了"跨市场比较必须对齐"，没写"整份报告统一"。现在补上。）

### 要求

1. `AS_OF` 是**全报告唯一基准日**，定义为：所有纳入的市场都已收盘的最近交易日。
2. **报告里出现的每一个数字**——正文、表格、卡片、图表标注、相对领导关系——
   一律以 `AS_OF` 为终点计算。**没有例外。**
3. 某个市场有比 `AS_OF` 更新的数据时：**丢弃**，不得混入。
4. 若确实想展示更新的数据，必须放进独立的
   `## AS_OF 之后的增量（不参与任何计算）` 区块，并逐条标注日期。
5. 每个市场在数据表里标出**它自己的实际最新日期**，以及**是否等于 AS_OF**。
   不准把日期不同的数据统统标成 `fresh`。

### 自检

> 全文搜索任意一个指标名，出现的所有数值必须一致。不一致即未通过。

## P1 · 参数必须标明是"测量值"还是"缺省值"

### 现在的问题

```
RISK_BUDGET: 0.30
依据：前瞻性数据与近 250 日分位缺失，风险预算按保守档设为 0.30
```

这个 0.30 不是对市场的读数，是**对"没有数据"的反应**。
意味着在数据接上之前，它每天都会是 0.30——**不携带任何市场信息**。
下游会把一个常量当成测量结果消费。

### 要求

参数块每一项都要配一个来源标记：

```yaml
RISK_BUDGET: 0.30
RISK_BUDGET_SOURCE: DEFAULT_ON_MISSING_DATA   # MEASURED | DEGRADED | DEFAULT_ON_MISSING_DATA
RISK_BUDGET_INPUTS: [<实际用到的输入项>]        # 为空则必须是 DEFAULT_ON_MISSING_DATA
```

- `MEASURED`：全部必需输入齐备，参数由数据算出
- `DEGRADED`：部分输入缺失，参数由剩余输入算出，须列出缺了什么
- `DEFAULT_ON_MISSING_DATA`：输入不足，此值是缺省档，**不反映市场状态**

`LONG_GATE / DISPERSION / SECTOR_PRIOR / BLACKOUT` 同样处理。

## P1 · 把历史拉到 300 个交易日以上

**这是本次投入产出比最高的一件事，如果只做一件就做这件。**

### 为什么

现在 HTML 里只有约 125 个交易日（2026-02-19 起）。因此
`指数近 250 交易日分位：missing`，`LONG_GATE` 只能常闭。

而"指数在长周期区间的位置"这个门，在 A 股个股数据上已经被实测验证过有效：
按大盘 250 日分位分层后，同一个个股信号在**高位档（280 个交易日）10 日超额 −1.41%，
t = −3.26**，一致显著为负。**它是目前唯一被证明有判别力的宏观参数。**

现在差的只是历史长度，不是新数据源——同样的接口多拉一段就行。

### 要求

1. 17 个市场的日线历史全部拉到 **≥ 300 个交易日**（能拉更多更好，越长分位越稳）。
2. `LONG_GATE` 改为可计算，并写出明确规则，例如：
   ```
   pct250 = 收盘价在最近 250 个交易日中的百分位
   pct250 > 0.70 → CLOSED    其余 → OPEN
   ```
   规则和当前读数都要写进报告，**不准用感觉判断**。
3. 历史不足 250 根的市场，单独标注，不参与该项计算。

## P1 · DISPERSION 现在就能算，不要报 UNKNOWN

### 为什么

`DISPERSION: UNKNOWN` 的理由是"个股与行业横截面离散度未获取"。
但**跨市场离散度用你手上这 17 个市场就能算**，不需要任何新数据。

它回答的问题很实在：**今天资产之间是各走各的，还是齐涨齐跌。**
齐涨齐跌时，下游选股那一层贡献很小，应该把精力放在方向和仓位上。

### 要求

```
1. 取 17 个市场当日收益率，算横截面标准差 → 今日离散度
2. 对历史每一天重复，得到时间序列
3. 报出今日读数 + 它在近一年的分位数
4. 分档：分位 > 60% → HIGH ；40~60% → MID ；< 40% → LOW
5. DISPERSION_SOURCE: MEASURED，并注明"跨市场口径，非个股口径"
```

**必须写清口径。** 跨市场离散度不等于个股离散度，别让下游误以为它能直接指导选股。
个股口径若日后接入，单独出一个 `DISPERSION_EQUITY`。

（参考：A 股个股口径当前读数为 2.45%，近一年 13% 分位，属 LOW。
数据在 `~/ashare-panel/data/panel.db` 的 `stock_daily` 表，如能访问可直接算；
访问不了就只出跨市场口径，并在台账里注明个股口径未接入。）

## P2 · 三处小问题

1. **`DATA_COVERAGE: 0.321429` 是假精度。** 14 个类别按固定权重折算，
   报到小数点后六位没有意义。统一保留两位：`0.32`。

2. **标题与结论不一致。** 标题写「防守 / DEFENSE」，正文写「本日不提供方向观点」——
   "防守"本身就是一个方向判断。既然不给方向，标题应为
   **「无方向观点 / NO VIEW」**，把 `RISK_BUDGET: 0.30` 作为副标题呈现。

3. **Markdown 导出丢字段。** HTML 里参数块八项齐全，`latest.md` 里
   `AS_OF / SECTOR_PRIOR / BLACKOUT` 三项丢失。两个格式必须包含完全相同的参数块。

## 不要做的事

- **不要为了让洞察区不空而降低标准。** 数据补齐之前洞察区继续留空是正确的。
- **不要用历史价格反推市场预期。** 原 prompt 那条规则继续有效。
- **不要把跨市场离散度当成个股离散度用。** 口径不同，混用会误导下游。
