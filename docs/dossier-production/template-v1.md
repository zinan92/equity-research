## 产业坐标

先把公司钉在产业地图上，再分析公司本身。固定回答四个问题：

- **产业链位置**：用“上游 → 公司 → 下游”说明它卡在哪个价值环节、需求如何传导。
- **国内同类坐标（研究判断）**：列出真正有比较意义的 2–4 家公司或市场简称，说明谁偏规模、谁偏技术、谁偏弹性；若不是同口径竞品，必须指出。
- **全球坐标（研究判断）**：列出国际标杆或替代路线，明确公司的领先点、代差与仍待核验的部分。
- **议价权与约束**：谁能卡它、它能卡谁；至少写一个上游约束和一个下游约束。

最后给一条大白话逻辑链：`需求为什么发生 → 为什么传到这个环节 → 公司凭什么拿到钱 → 哪一步断掉会证伪`。竞争名称可作为研究框架，但排名、份额、技术代差等事实必须有独立来源，不能从市场绰号倒推。

## 一句话定位

**唯一性定位（研究判断）**：必须用一个有方向性的资产标签回答“它凭什么不是另一家普通公司”。可以使用“第一、最强、最硬、弹性之王、平台王者”等强词，但同一句必须限定比较范围和判断依据；没有可核验的比较基础时不得把强词伪装成事实。

`[F-01]` 紧接一条来源支持的事实，解释上述定位来自什么产品、业务结构或竞争机制。

**一句话结论**：必须站队，明确“最强优势 + 当前代价 + 适合什么资金”；把最重要的证伪条件写进结论，不用方法论或免责话术冷启动。

## 财务与估值

用三条短段落完成，不放财务大表：

- **三年增长**：至少覆盖最近 3 个完整年度，解释收入与利润趋势。
- **盈利质量**：用最新季度、现金流、毛利率或 ROE 判断增长质量；只放统一期间、币种和口径的数字。
- **估值**：列出 point-in-time 价格、市值和 PE/PB；双源冲突并列，不挑一个“好看”的数字。没有可靠快照则明确写 valuation gap。
