# 中际旭创｜公司档案

> **阅读方式**：中际旭创的上市公司控制权与光模块技术经营权来自两条不同路径：王伟修体系提供上市平台与控制权，刘圣团队建立苏州旭创并负责技术经营。下面把这套治理结构、产品代际、客户集中和当前估值放在一起审视。

## 1. 一句话定位

`[F-01]` 中际旭创研发、生产和销售高端光通信收发模块，面向云计算数据中心和数据通信场景提供 100G、200G、400G、800G 与 1.6T 产品；2025 年光通信收发模块占收入 97.95%。[S-01]
**研究判断**：公司是高度聚焦的 AI 网络硬件供应商，投资结论取决于高速率代际份额、客户集中、产品降价与产能扩张之间的动态，而不是仅看行业带宽增长。

### 人和组织

- **刘圣**生于 1971 年，博士，曾任美国朗讯研发工程师、Pine Photonics 中国研发中心负责人、Opnext 产品研发高级经理；2008 年创办苏州旭创，2023 年起任上市公司董事长兼总裁。[S-01]
- **控制权并不在技术创始人一人手中**：山东中际投资控股持股 10.99%，王伟修直接持股 6.28%，二者为一致行动人；王伟修是实际控制人。[S-01]
- 王晓东长期担任常务副总裁并在山东中际体系任职；财务负责人王晓丽有普华永道和投资管理经历。**研究判断**：公司是“控股股东资本平台 + 海归技术团队 + 专业财务管理”的组合，不应被简化成单一创始人公司。[S-01]
- 2025 年前五大客户收入占 75.98%，其中关联方销售占年度收入 8.10%。治理与客户结构必须一起看，因为高速增长高度依赖少数采购方。[S-01]

### 从创业公司到上市平台核心资产

- 2008 年刘圣创办苏州旭创，团队履历集中在光通信研发；2016 年前后，苏州旭创通过重大资产重组进入原中际装备上市平台，2017 年起刘圣进入上市公司管理层。[S-01]
- 产品升级并非只换一个速率标签：400G、800G、1.6T 需要更高速 DSP、光芯片、封装、散热和测试协同，客户验证与良率决定能否把展示样品变成收入。[S-01]
- 公司在 2020 年展示 800G 可插拔模块，随后陆续展示 1.6T、硅光、LPO 和相干方案；**研究判断**：多路线研发降低押错技术的风险，但无法证明每条路线都能取得商业份额。[S-01]
- 2025 年研发人员增至 2,169 人，同比增长 49.28%，研发人员占比 18.66%；研发扩张速度明显快于组织整体，反映公司正在为下一代产品前置投入。[S-01]

## 4. 商业模式与业务线

光模块把交换芯片或 GPU 集群产生的电信号转换为可在光纤上传输的光信号。客户不是因为“AI”三个字下单，而是按交换架构、距离、功耗、速率和可靠性认证产品。收入增长来自数据中心建设、800G/1.6T 产品结构升级和产能交付；同一代产品普及后，价格下降与竞争会反向压缩毛利。[S-01]

## 8. 研究结论与待补问题

- **事实结论**：2025 年和 2026 年第一季度收入、利润高速增长，光模块业务、境外收入和直销高度集中。[S-01][S-02]
- **研究判断**：当前财务表现支持高速模块景气，但集中度使公司对少数客户资本开支和技术路线高度敏感；“AI 需求强”不能替代订单、份额、良率和现金转换验证。
- **市场在交易什么**：当前定价要求高速模块需求、产品代际份额和毛利率同时维持强势；若前五大客户采购放缓、产品价格下降快于成本或 1.6T/CPO 路线切换失误，高估值会放大经营波动。[S-01][S-03][S-04]
- **待补问题**：前五大客户的逐年集中度、800G/1.6T 销量与均价、产能和良率、关键光芯片/DSP 供应、库存与应收账龄、股权激励稀释仍需补齐。[S-01]
