# 贵州茅台｜公司档案

> **证据边界**：本档案只使用公司在巨潮资讯披露的年度报告与一季报。品牌强弱、稀缺性和渠道质量均按可证伪假设处理，不用二级市场叙事替代证据。

## 1. 一句话定位

`[F-01]` 贵州茅台的主营业务是茅台酒及系列酒的生产与销售，产品通过直销和批发代理渠道销售；2025 年茅台酒收入占酒类收入的主要部分。[S-01]
**研究判断**：产品价值的核心约束不是短期产量，而是至少五年的生产到出厂周期、渠道价格秩序和高端消费需求能否长期匹配。

## 8. 研究结论与待补问题

- **事实结论**：2025 年公司收入和利润同比下降，茅台酒收入小幅增长、系列酒和批发渠道收缩；2026 年第一季度收入恢复增长但利润增速较低。[S-01][S-02]
- **研究判断**：长工艺周期和高毛利支持稀缺供给叙事，但决定长期回报的是终端真实需求、价格秩序与渠道库存，而不是厂商口径的品牌排名。
- **待补问题**：终端批价与真实成交价、经销商库存天数、直营用户复购、系列酒各产品销量、集团与上市公司的关联交易经济性仍需独立数据。
