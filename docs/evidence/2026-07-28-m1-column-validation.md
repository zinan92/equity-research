# M1 · 双列与跨年页级事实校验

## 已执行的回溯审计

对宁德时代 2021–2025 五份 CNINFO 年报运行了双列事实与跨年比较。

| 相邻年报对 | 可比科目对 | 一致 | 不一致 | restated |
| --- | ---: | ---: | ---: | ---: |
| 2021/2022 | 3 | 3 | 0 | 0 |
| 2022/2023 | 2 | 2 | 0 | 0 |
| 2023/2024 | 2 | 2 | 0 | 0 |
| 2024/2025 | 2 | 2 | 0 | 0 |

总计 9 对，9 对一致。基线营收是 `362,012,554 千元`：2024 年报
`1222806982` p119 的本期列，与 2025 年报 `1225002214` p116 的上期列一致。

## 校验结果与缺口

- 每个有可识别表头的双列行保留两条事实：本期与上期，后者的 `report_period`
  回退一年，document/page 保持当前年报身份。
- 未识别表头时，第二列不猜测；只保留第一数值并标
  `column_identity_unresolved`。
- 资产负债表平衡校验已对五期执行，但全部为 `missing_balance_sheet_component`：
  当前 state machine 在资产负债表表头/列身份未被解析时不把候选纳入方程，
  而不是用可能错列的数字强行得出平衡。
- 本次 9 个跨年可比对中没有发现错误或追溯调整；零发现基于实际 9 次比对。

## 股本语义

`share_capital_amount` 是资产负债表货币金额；`shares_outstanding` 是现有总股数。
二者不互相替代。可参与分配股数及库存股扣除将在专门事实字段中继续保持独立。
