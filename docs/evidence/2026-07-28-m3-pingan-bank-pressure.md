# M3 · 平安银行压力测试

官方年报：CNINFO `1225022887`（2025 年年度报告）。该路径在提取前即被行业适用性
边界阻断：C2 是制造业无杠杆 DCF，不适用于银行。

## 原始片段

- `净息差 = 利息净收入/平均生息资产余额`（年报约 p981–984）。
- `吸收存款本金 3,582,755`、`发放贷款和垫款本金总额 3,390,840`（p932–943，人民币百万元）。
- `核心一级资本充足率 9.36%`、`资本充足率 13.77%`（p1024–1041）。

## 结构性差异

| 制造业 DCF 输入 | 银行等价事实 | 结论 |
| --- | --- | --- |
| 营业收入/营业成本 | 利息净收入、净息差、信用减值 | 经济含义不同 |
| capex 与营运资本 | 贷款、存款、风险加权资产 | 不可作为普通 NWC |
| 债务/现金 | 存款和同业负债是核心经营负债 | 不可净债务化 |
| ROE/FCF DCF | CET1、资本充足率、拨备与股利 | 需剩余收益或股利折现模型 |

## 结论

不执行 C2、不填零值、不生成 target price。支持银行需要新估值模型和银行 profile，
不仅是科目映射。这是 E3-S5 三行业 profile 的直接输入。
