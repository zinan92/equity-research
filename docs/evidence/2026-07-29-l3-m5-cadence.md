# L3-M5 · Research cadence state

The cadence contract has three lanes: slow (30/45 days), periodic (1/3 days), and fast (18 hours/2 days). The current orchestrator receives only fast-lane last-good evidence from an activated canonical snapshot. Slow and periodic remain `missing` until their own successful receipts exist.

Tests prove deterministic fresh/due/stale/missing states and that an injected refresh failure preserves the prior active snapshot and its fast `last_good_at`. This is intentional: a failed run never overwrites last-good.

Validation: `python3 -m unittest product.tests.test_research_cadence product.tests.test_snapshot_orchestration -q` (9 tests passed).
