## provisional 审阅优先级

1. **WACC / terminal growth**：直接改变 DCF 分母和终值，目标价方向分别为 WACC 上升则下降、永续增长上升则上升。
2. **收入增速 / EBIT margin 情景**：改变五年 FCF；上调提高 target price。
3. **营运资本现金流三项的归集规则**：影响 FCF，净营运资本投资提高则 target price 下降。
4. **评分阈值/权重**：当前不改变 no_action，但未来覆盖放行后会改变仓位政策。
