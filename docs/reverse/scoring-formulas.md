# N1-4 已披露评分公式复现

## 范围与边界

本文只记录公开页面已经披露、可由输入重算的算术。它不是产品评分规则，更不导入任何归档公司的分数、等级或文字结论。

运行时验证由 `scripts/validate_disclosed_scoring.py` 读取外部本地归档，输出 JSON 审计报告到调用者指定路径。归档不进入 Git。

## 综合分

设成长、质量、估值安全、资金关注分别为 `G/Q/V/A`，则：

```text
raw = 0.28G + 0.12Q + 0.13V + 0.08A
composite = round(raw / 0.61)
```

`0.61` 是这四个可量化部分的权重和；实现使用多数样本可复验的最近整数序列化。少数残差含不一致的 0.5 tie 或显式覆盖，验证器会列为 residual，不会为了拟合它们而全局篡改公式。任一输入缺失或不是有限数值时不输出分数。

## 机会分

```text
opportunity = round(0.45G + 0.20Q + 0.35V)
```

同样要求三个输入都可用，不做缺失值填充。

## PEG 分档

| PEG | 标签 |
| --- | --- |
| `< 1` | 便宜 |
| `1 ≤ PEG < 2` | 合理 |
| `2 ≤ PEG ≤ 4` | 偏贵 |
| `> 4` | 极贵 |

`PEG` 缺失时结果为空，而不是“合理”。

## S/A/B 等级

等级页的 `score` 与 `grade` 不是一一映射：同一可见分数会出现多个等级，且绝大多数行没有护城河、利润率或三高输入。因此不得拟合一个伪精确阈值公式。验证器会把它明确输出为 `manual_judgment_not_formulaically_reproducible`，直到具备完整、可归因的输入与人工覆盖记录。
